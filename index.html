Privacy-Preserving Federated Sequential Recommendation

Master's thesis at NIT Patna solving user trajectory and interaction leakage in centralized recommender models using Locally Differentially Private (LDP) mechanisms.

ARCHITECTURAL FORMULATION
[Client Interaction] → [LDP-SeqMask Noise] → [View-CL Invariance] → [Laplace Aggregation]
  • LDP-SeqMask: Formulated local sequence perturbation so raw interaction clickstreams never leave edge client devices.
